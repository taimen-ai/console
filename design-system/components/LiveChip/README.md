# LiveChip

Небольшой чип связи: «online · 14:02» или «offline · данные на 13:40».

**Когда.** В `AppShell.status` — в верхнем отступе экрана, не сдвигая сетку. В `TopBar` индикатор отключается (`showLive={false}`). Без связи — серый пустой кружок и время последних данных; критичное поверх показывает `DegradedBanner`.

**Потребитель передаёт.** `live`, `at`.
