# Combobox

Выбор из длинного списка поиском: человек, агент, сервис, тип работы, пространство.

**Когда.** Вариантов больше, чем помещается взглядом, или их число не известно заранее:
исполнитель, ответственный, тип работы, пространство в шапке. Короткий закрытый выбор
(2–4 варианта) — переключатели или `PersonPicker`.

**Как ведёт себя.** Закрыт — в поле выбранное. Фокус или ввод открывают список, ввод его
сужает (без учёта регистра и «ё»; ищет по названию, `meta`-строке и `search`). ↑↓ — по
вариантам, Enter — выбрать, Esc — закрыть (диалог вокруг не закрывается). `clearLabel` —
первый вариант «ничего не выбрано» (`value: null`). Исполнитель — с глифом вида (`kind`),
пространство — с отступом уровня (`depth`). Вариант без нужной роли — `warn`.

**Потребитель передаёт.** Только допустимые варианты: исполнителей, которые могут взять
этот тип работы, типы, разрешённые в пространстве. Отфильтрованное — не показывается.

**Доступность.** Шаблон combobox + listbox (WAI-ARIA 1.2): `aria-expanded`,
`aria-controls`, `aria-activedescendant`, варианты `role="option"`.
