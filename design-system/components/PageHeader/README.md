# PageHeader

Шапка страницы объекта: путь, статус, заголовок с глагола, фраза готовности, действия справа.

**Когда.** Страницы одной работы, документа, раздела. Номер (`TASK-000845`) — вторым слоем в пути. Действия — управляющие (`Передать`, `Снять`, `Изменить`); главное «нужен человек» — в зоне решения, а не здесь.

**Потребитель передаёт.** `crumbs`, `number`, `status` (`StatusMark`), `title`, `lead`, `actions`.
