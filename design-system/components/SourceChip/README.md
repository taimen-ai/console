# SourceChip

Чип источника знания: ядро (`authoritative`), память (`recalled`), внешняя система (`external`).

**Когда.** Рядом с фактом, если источник не очевиден: ответ ассистента, основание в хронике, данные из 1С/ЕИС. Три источника различаются рамкой (сплошная / точечная / штриховая) и иконкой, а не только цветом.

**Потребитель передаёт.** `label` («из 1С»); `freshness` для памяти и внешнего источника.

**Нельзя.** Сливать память с фактами ядра; показывать `recalled` без свежести.

**`iconOnly`** — только значок с рамкой своего вида (сплошная — ядро, точками — память, штрихом — внешняя система); слово — в подсказке и `aria-label`. В ленте ассистента источник показывается так.
