# ExecutorCard

Карточка исполнителя в «Парке»: identity block, состояние словами, «сейчас», «что доверено».

**Когда.** Правая колонка пульта (порядок: с проблемами → занятые → свободные), список исполнителей. `vacant` — пунктирная карточка «Некому: роль» с действиями «Назначить» / «Поручить агенту».

**Потребитель передаёт.** «Что доверено» одной строкой из объявлений пакета; где не объявлено — `trusted={null}` → «полномочия не объявлены». Инфраструктура (узлы, реплики, ревизии) — второй слой, не здесь.
