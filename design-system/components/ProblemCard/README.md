# ProblemCard

Карточка проблемы: диагноз на языке организации, место, с какого момента и путь вперёд рядом.

**Когда.** Зона «Сломано / застряло», раздел «Работа» (группа «стоит»). `failed` — упало / не прошла проверку; `blocked` — нечем или некому; `approaching` — приближение к пределу, серым пунктиром, до факта. `ProblemCard.Calm` — «Всё штатно» со временем последней проверки.

**Потребитель передаёт.** Диагноз из проекции пульса; действия из каталога действий — различать «повторить как было» и «изменить и продолжить».

**Нельзя.** Коды ошибок в первом слое; проблема без действия.

**`row`** — строка на всю ширину зоны: диагноз в одну строку, место и время, действие справа. Действия — `{ label, variant, onClick }`; каждое управляющее действие открывает `Dialog` с `Consequences`: «Передать человеку», «Повторить как было» (с предупреждением, если данные не менялись), «Снять» (снятие не откатывает внешние действия).
