# Icon

Значки системы по имени: контур 1.5px в сетке 16, цвет — `currentColor`.

**Когда.** Внутри компонентов и в разметке экранов: поиск, раскрытие, файл, разделы меню, отметки состояний. Значок со смыслом получает `label`; декоративный — нет.

**Нельзя.** Иконки, намекающие на разработку ПО или «ИИ» (см. README системы); цвет значком без слова.
