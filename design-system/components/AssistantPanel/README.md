# AssistantPanel

Панель ассистента (⌘J) справа: видимая и отключаемая плашка «ассистент видит: …», беседа, поручение словами.

**Когда.** С любого экрана; ни один сценарий консоли не требует чата. «Спросить, почему стоит» у застрявшего открывает панель с вопросом. Исход поручения — типизированная работа в ядре с подтверждением (`proposal`), не сообщение.

**Потребитель передаёт.** `context` — что на экране; ответы с `SourceChip`.

**`docked` (2026-10-02).** Панель справа на всю высоту внутри `AppShell`: шапка «Ассистент · ⌘J · Закрыть». **Беседа одна** — та же, что в Telegram: кнопки «Новая беседа» нет, лента с разделителями «Вчера / Сегодня / Новое», у сообщения время и канал («из Telegram», «и в Telegram»), у вопроса — экран, данные которого ушли с ним («по экрану «Сегодня»»). **Контекст экрана передаётся данными, а не скриншотом**; плашки о контексте в панели нет. **Ассистент проактивный**: пишет сам с подписью «Источник: процесс «Оплата счетов»» и действиями в сообщении (`actions[].onClick`); если нужен человек — рамка accent. Панель сама не открывается — счётчик на кнопке в `TopBar`. Источник ответа — только значок (`SourceChip iconOnly`), слово — в подсказке. Поручение — предложение работы с полями «Будет заведено» (`fields`) и `onAccept`; работа заводится только после «Завести работу». Над полем ввода — быстрые вопросы по экрану; Enter — отправить, Shift+Enter — перенос; поле без обводки фокуса.

**Языки.** Встроенные подписи («Ассистент», «Закрыть ассистента», «Смотрю…», плашка «Источник: …», «из / и в Telegram», «по экрану …», подсказка Enter/Shift+Enter, приветствие пустой беседы) — из словаря по локали (`LocaleProvider`, иначе `lang` документа). Текст сообщений, подсказки-вопросы, `hello`, `acceptLabel`, поля предложения приходят данными и не переводятся.
