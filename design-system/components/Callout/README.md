# Callout

Предупреждение или пояснение внутри формы и диалога.

**Когда.** `warning` — выбор, который обходит правило: «У Ирины нет роли «Бухгалтер» — назначение мимо очереди, будет видно в истории». `info` — пояснение без риска.

**Нельзя.** Подменять им последствия действия (`Consequences`) или ошибки (`ProblemCard`).
