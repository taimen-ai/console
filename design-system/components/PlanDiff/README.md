# PlanDiff

План пакета словами: «что изменится, если установить» — было → станет, владение полем, судьба открытых дел.

**Когда.** Правила игры → Пакеты. Консоль не редактирует объявления: она показывает план и применяет ровно его («Установить ровно этот план», вариант `brand`), хэш плана — в техническом слое.

**Потребитель передаёт.** Пункты плана ядра, переведённые в фразы пакетом.
