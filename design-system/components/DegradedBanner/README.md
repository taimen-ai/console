# DegradedBanner

Честная деградация: баннер «данные на 13:40» / «ядро недоступно» и секционная ошибка «источник не ответил».

**Когда.** `stale` — нет живого соединения, данные есть. `down` — ядро недоступно, действия отключены, есть «Повторить». `DegradedBanner.Section` — одна секция не ответила, остальные живут.

**Нельзя.** Рисовать нули или пустоту вместо «нет данных»; прятать время последних данных.
