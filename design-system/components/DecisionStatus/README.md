# DecisionStatus

Что стало с решением после нажатия: нажатие кнопки — ещё не подтверждённое действие системы.

**Когда.** Заменяет кнопки `DecisionCard` (через `footer`) после нажатия. Строки: «Отправляю решение…» → «Записано в ядре 14:31» (только после ответа ядра) → «Исполняется: …» → «Исполнено: …». Отказы — словами и с путём: «Не записано: Ирина Котова уже приняла» → «Обновить»; «Не записано: данные изменились — проверьте заново» → «Показать изменения»; «Не отправлено: нет связи — решение не записано» → «Повторить».

**Потребитель передаёт.** Ответ ядра на решение и исход (`approval outcome`).

**Нельзя.** Показывать «готово» до ответа ядра; прятать отказ в toast.
