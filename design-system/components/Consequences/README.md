# Consequences

Последствия действия до кнопки — по формуле «что произойдёт → охват → обратимо ли → что уже сделано вовне».

**Когда.** В каждом `Dialog` управляющего действия. Строки: «Текущая попытка» (что станет с ней), «Что уже сделано вовне» (отмена работы не откатывает внешние действия — так и пишется), «Дело процесса», «Можно ли повторить», «Обратимо ли». `tone`: `ok` — ничего не менялось или безопасно; `warn` — заметное или необратимое (подложка `warning-bg`); `info` — нейтрально.

**Потребитель передаёт.** Строки из ядра: шаги попытки, исход решения, состояние дела.

**Нельзя.** Обещать откат того, что ядро не откатывает.
