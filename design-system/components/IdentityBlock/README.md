# IdentityBlock

Единый identity block для человека, агента и процесса: глиф, имя, роль или версия, «что делает сейчас».

**Когда.** Строка «Выполняет»/«Отвечает», «кто просит» в решении, Парк, список исполнителей. Одна анатомия — это и есть «одна модель исполнителей».

**Потребитель передаёт.** `meta`: роль человека («Финансовый директор») или версию («r7», «v2»); `now` — фразу из фактов ядра. `inline` — в мета-строке карточки.

**Нельзя.** Рейтинги и проценты у людей (у людей — факты без долей); машинные id в `name`.
