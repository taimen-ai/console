# ChannelChip

Чип доставки в канал человека: «в Telegram · доставлено 12:40», «решено из Telegram 12:41».

**Когда.** Карточка решения, хроника (группа «Доставка людям»), журнал. Это доказательство, что работа дошла до человека в его инструменте, — без него на демо интеграции «не существует».

**Потребитель передаёт.** `channel`, `state` из журнала доставок notification-service, `at`; при `failed` — `reason` словами («бот заблокирован»).
