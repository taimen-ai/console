# NavDrawer

Меню слева: организация, разделы со счётчиками, настройки и участник внизу.

**Когда.** Внутри `AppShell`. Открывается кнопкой ☰ в `TopBar`. Шапка — организация (переключатель), «Закрепить меню», «Закрыть». Текущий раздел — полоса `brand` и жирное начертание. Счётчик «ждёт человека» — `accent`, остальные нейтральные. `placeholder` — заглушка пункта, пока состав не задан.

**Потребитель передаёт.** `org`, группы пунктов с `href`/`onClick`, `pinned` и `onPin` (закрепление — только от 1280px), `onClose`, `footer` (настройки и участник).

**Нельзя.** Accent на счётчике, если это не ожидание человека; больше одного активного пункта.
