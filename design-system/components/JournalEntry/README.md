# JournalEntry

Запись журнала-повествования: кто (глиф) · что сделал · с чем · почему; канал решения; аварийные пути выделены.

**Когда.** «Что произошло» на пульте, Аудит → Журнал. Работа правил отличима от работы людей глифом. `emergency` — аварийный вход, принудительная остановка, ручное отключение: подложка `warning-bg` и метка «Аварийно».

**Потребитель передаёт.** Фразу события из словаря консоли; полный JSON — технический слой по клику.
