# Criteria

Критерии приёмки работы: что проверяется, каким способом и что с каждым сейчас.

**Когда.** Сведения работы, форма «Поручить работу» (критерии объявляет тип работы), карточка решения. Вид проверки словом: «автопроверка», «внешнее состояние», «человек», «оценка модели». Приёмка человеком — сама последний критерий.

**Потребитель передаёт.** Критерии типа работы и состояние последней проверки (`ok`, `bad`, `wait`).

**Нельзя.** Предлагать «принять» работу с непройденным автоматическим критерием — такой операции нет: работа возвращается исполнителю.
