# Chronicle

История одной работы — одна вертикальная хроника с группами и тремя видами: «Кратко», «По времени», «Полный журнал».

**Когда.** Страница `/console/work/:publicId`. Группы по порядку: Основание → Доставка людям → Взято → Попытки → Результаты → Проверка → Подписи → Обсуждение → Порождённое → Сверка → Что изменилось. Работа машины — сплошная линия `machine-line`; ожидание и действия человека — пунктир. Отсутствующее звено — пунктирный блок с причиной («нет прав», «ядро не знает», «источник не ответил»).

**Потребитель передаёт.** Группы из `GET /tasks/{ref}/timeline`; протокол попытки — в `box` (раскрываемый ящик, «размышления не хранятся» — явно).
