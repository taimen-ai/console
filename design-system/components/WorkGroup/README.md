# WorkGroup

Сворачиваемая группа строк работы по нужде: «Ждёт вас», «Застряла», «В работе», «Не начата», «Сделано и проверено сегодня».

**Когда.** Экран «Работа». «Ждёт вас» — `human` (полоса accent). «Сделано» свёрнута по умолчанию. Внутри — `WorkRow`; список объявлен контейнером `workrows`: на узкой ширине строки складываются, действие и давность — в колонках постоянной ширины справа.

**Потребитель передаёт.** Строки группы (одна категория статуса — один запрос), число, «Показать ещё»: `more` числом — «Показать ещё N», `more: true` — «Показать ещё» без числа, когда сколько осталось неизвестно (у источника нет счётчика).
