# TopBar

Строка состояния (зона 0): бренд, организация и дата, живое соединение, период, ⌘K, ⌘J, участник.

**Когда.** Одна на всех экранах консоли. Зона бренда — BRAND-слой: `brand.name` и `brand.mark` из конфигурации тенанта, цвет — токен `brand`, шрифт — `--font-brand`.

**Потребитель передаёт.** `org`, `date` («Сегодня, 29 сентября»), `at`; `live={false}` при потере соединения — «данные на 13:40».

**Нельзя.** Машинные строки в шапке (id тенанта, версии, хэши); имя продукта в компонентах — только из конфигурации.

**Каркас (2026-10-02).** Слева — кнопка меню ☰ (`onMenu`, `menuOpen`, `menuId`), затем знак и **название организации** (без `brand.name` на месте имени продукта стоит `org`, второй раз оно не повторяется), дата. Индикатор связи выносится в `LiveChip` (`showLive={false}`): «online · 14:02» / «offline · данные на …». Справа — поиск ⌘K, аватар участника и последней — кнопка **«Ассистент ⌘J»**, залитая `brand`, со счётчиком непрочитанного (`assistantUnread`; `assistantUrgent` — accent, если среди новых есть «нужен человек»). Пока ассистент открыт, кнопки нет.

**Только работающее (2026-10-02).** Переключатель периода показывается, только если передан непустой `periods` (выбор — `onPeriod`), поиск ⌘K — только если передан `onSearch`. Без них этих кнопок нет: строка состояния не обещает того, чего экран не умеет.

**Языки.** Подписи кнопок и `aria-label` (меню, период, поиск, «Ассистент», «новых сообщений: N»), а также `LiveChip` («offline · данные на …» / “offline · data as of …”) — из словаря по локали. `org`, `date`, `periods` — данные: дату и названия периодов приложение форматирует само на языке экрана.
