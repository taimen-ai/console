# Field

Поле формы: подпись, подсказка и сам ввод (`tc-input`, `tc-select`, `tc-textarea`).

**Когда.** Формы «Поручить работу», «Передать человеку», причины снятия. Сетка — класс `tc-form` (две колонки, одна — на узком); `wide` — на всю ширину.

**Потребитель передаёт.** `label`, `help`, сам ввод. Обязательность и ошибка — словами рядом с полем.
