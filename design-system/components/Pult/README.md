# Pult

Главный экран консоли («Полярис · Сегодня, 29 сентября») — композиция компонентов системы, не отдельный компонент.

Семь зон: 0 строка состояния (`TopBar`) · 1 «Итог» (`Summary`) · 2 «Ждёт вашей подписи» (`DecisionCard`, единственная зона с акцентом — полоса `accent` сверху) · 3 «Сломано / застряло» (`ProblemCard`, полоса `error` только при проблеме) · 4 «Путь работы» (`WorkPath`) · 5 «Парк» (`ExecutorCard`) · 6 «Рычаги» · 7 «Что произошло» (`JournalEntry`).

Сетка: левая колонка `minmax(0, 1fr)`, правая — `layout-rail` (360px); зазор и паддинг зон — `--zone-pad` из плотности. На телефоне — стек: Итог → Ждёт подписи → Сломано → Путь (числа) → Парк (горизонтальная прокрутка) → Рычаги.

Штатно зоны 2 и 3 пусты и спокойны (`EmptyState` без действия, `ProblemCard.Calm`), глаз идёт к «Итогу» и «Пути». Данные превью — демо-организация: оплата счетов и тендерный отдел.

**Экран «Сегодня» (2026-10-02).** Состав изменён: слева «Итог» (`Summary compact`), «Сломано / застряло» (появляется только при проблемах, `ProblemCard row`), «Поток работы» (`WorkPath look="flow"`), «Что произошло»; справа сверху «Ждёт вашей подписи» (`DecisionCard compact` + `collapsed`), ниже «Сейчас в работе» (`IdentityBlock` + `StatusMark` строками). «Парк» заменён на «Сейчас в работе», «Рычаги» перенесены в настройки. В одну колонку (рабочая область ≤ 880px): Итог → Сломано → Ждёт подписи → Поток → Что произошло → Сейчас в работе. Каркас — `AppShell`. Живой макет — `prototype/index.html` в репозитории консоли.
