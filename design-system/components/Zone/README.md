# Zone

Зона экрана: карточка с заголовком и числом или ссылкой справа.

**Когда.** Основной блок экранов: «Итог», «Ждёт вашей подписи», «Сломано / застряло», «Материалы». `tone="human"` — полоса accent: зона, где ждут человека; `tone="problem"` — полоса error, только пока в зоне есть проблема.

**Потребитель передаёт.** `title`, `count` или `action`, содержимое.

**Нельзя.** Две зоны с accent рядом без причины; полоса error у пустой зоны.
