# ExecutorGlyph

Глиф вида исполнителя: круг — человек, скруглённый квадрат — агент, шестиугольник — процесс или правило.

**Когда.** Везде, где назван исполнитель: identity block, печати, хроника, журнал, палитра. Вид читается формой, не цветом: человек — нейтральный (`glyph-human-*`), агент и процесс — цвет машины (`glyph-machine-*`).

**Потребитель передаёт.** `kind`, `name` (для инициалов и `aria-label`), для агента и процесса — `label` из 2 знаков (ключ агента, аббревиатура процесса). `waiting` — пунктир ожидания человека; `vacant` — пустой пост роли.

**Нельзя.** Роботы, лица, аватарки-фото вместо глифа агента; антропоморфная анимация; цвет как единственное различие.
