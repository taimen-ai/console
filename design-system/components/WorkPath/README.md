# WorkPath

«Путь работы»: пять стадий цикла (Возникло → Поручено → Исполняется → Проверено → Изменило) + хвост «Сверено / снято» и ворота между ними.

**Когда.** Центр пульта. В стадии — число за период и разбивка по виду исполнителя (глифы) и по происхождению. В воротах — число застрявшего на переходе и причина словами. Ворота с элементами смотрящего — `mine`, тёплый акцент.

**Потребитель передаёт.** Агрегаты ядра по стадиям и воротам за период и охват.

**Нельзя.** Карточки работ внутри (это не канбан — карточки живут в разделе «Работа»).

**`look="flow"` (2026-10-02)** — вид для пульта: числа стадий через стрелки, под числом одна полоса «люди / агенты / процессы» (точные числа — в подсказке), застрявшее на выходе из стадии — строкой под ней (`gates[i]` относится к стадии i; `mine` — accent «ждут вашей приёмки»), без пунктирных ворот и прочерков; хвост «Снято» — отдельно справа, легенда цветов сверху. Стадии «Изменило» нет, пока мера результата не объявлена пакетом.

**Языки.** Подписи стадий (`label`), причины в воротах и происхождение — данные. Из словаря по локали — легенда «люди / агенты / процессы» (people / agents / processes), подсказки полосы, `aria-label` пути и потока, «N застряло» / «переход свободен».
