# LocaleProvider

Язык встроенных строк компонентов для поддерева: `en` (основной язык открытой поставки) или `ru`. Разметки не добавляет.

**Когда.** Один раз в корне приложения: `h(T.LocaleProvider, { locale: "en" }, app)`. Ближайший провайдер побеждает — экран или превью может показать другой язык внутри.

**Без провайдера.** Компонент берёт язык документа: `<html lang="ru">` → ru, `lang="en…"` → en, иначе — en; вне браузера (нет `document`, серверный рендер) — en. Поэтому превью и прототип с `lang="ru"` русские без правок, а приложение передаёт локаль явно, чтобы серверный и клиентский рендер совпадали.

**Хук.** `useLocale()` возвращает текущую локаль (`"en" | "ru"`): по ней приложение форматирует свои данные — даты, суммы, названия периодов.

**Что переводится.** Только встроенные строки из словаря `STRINGS`: подписи кнопок по умолчанию, `aria-label`, слова статусов, печатей и каналов, пустые и аварийные тексты, формы числа (`Intl.PluralRules`). Данные из пропсов — заголовки, фразы последствий, причины, имена — компонент не переводит: они приходят уже на языке экрана.

**Нельзя.** Строка интерфейса прямо в коде компонента; строка только на одном языке; склонение числом руками вместо форм словаря. Словарь — [vocabulary.en.md](../../vocabulary.en.md) и [vocabulary.md](../../vocabulary.md).
