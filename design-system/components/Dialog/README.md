# Dialog

Модальное окно действия: заголовок, пояснение, содержимое, подвал с подсказкой обратимости и кнопками.

**Когда.** Управляющие действия, которым нужен выбор или подтверждение: «Передать человеку», «Снять работу», «Остановить попытку», «Поручить работу» (`wide`). Внутри — `Consequences` до кнопки. Необратимое — `alert` и `hint` «Необратимо: …», кнопка `danger`.

**Потребитель передаёт.** `title`, `sub`, `hint`, `footer`, `onClose`. Компонент держит фокус внутри, закрывается по Esc и клику по подложке, возвращает фокус туда, откуда открыли.

**Нельзя.** Диалог для информации без действия; кнопка подтверждения без последствий.
