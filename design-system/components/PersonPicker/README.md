# PersonPicker

Выбор исполнителя списком: имя, роль и занятость, недоступные — выключены.

**Когда.** «Передать человеку», «Назначить». Список начинается с людей нужной роли; человек без роли — с `warn` («нет роли «Бухгалтер»»), и выбор такого показывает `Callout`. Роль — правило подбора исполнителя, полномочия — отдельно.

**Потребитель передаёт.** Людей с ролями из ядра, занятость, отсутствие.
