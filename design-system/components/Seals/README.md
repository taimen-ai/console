# Seals

Четыре печати работы: Откуда · Кто делал · Чем доказано · Кто подписал (+ канал).

**Когда.** На каждой строке работы (строчный вид) и в шапке истории работы (`labelled`). Это одновременно одна модель исполнителей и доказательство результата.

**Потребитель передаёт.** Четыре объекта из проекций происхождения, попыток, проверки и решений ядра. `null` — звено отсутствует: печать рисуется пунктиром со словом («не поручено», «не проверялось»), а не пропадает. Способ проверки: `external` / `auto` / `human` — галочка `success`; `model` — помечено отдельно, без галочки; `failed` — треугольник.

**Нельзя.** Цветные пилюли вместо словесно-графических марок; «проверено» без вида проверки.
