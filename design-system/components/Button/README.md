# Button

Кнопка консоли; вариант `human` — единственное на экране главное действие, которое ждёт человека.

**Когда.** `human` (заливка `accent`, текст `on-accent`) — подписать, принять, разблокировать: то, ради чего человек открыл экран. Одна на экран. `brand` — главное действие настройки («Установить ровно этот план»). `secondary` — «Отклонить…», «Назначить». `ghost` — «Открыть историю», «Не нужно было показывать». `danger` — только аварийные пути (принудительная остановка), всегда через AlertDialog.

**Потребитель передаёт.** Текст с глагола; `kbd` — клавишу, если действие доступно с клавиатуры (`E` для рискованного — с подтверждением).

**Нельзя.** Две `human` на одном экране; `human` для действий машины или настройки; pill-форма; белый текст на `accent` (3.4:1).
