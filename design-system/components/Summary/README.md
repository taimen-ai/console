# Summary

«Итог» пульта: одна фраза display-кеглем с числами-ссылками и полоса «Изменилось».

**Когда.** Верх главного экрана. Фраза меняется с периодом. Каждое число — ссылка в список «Работа» с фильтром. Полоса «Изменилось» — карточки измеренных изменений по типам работы с печатью способа проверки и ссылкой на evidence.

**Потребитель передаёт.** Числа из агрегатов ядра; `unit` с правильной формой числа. Суммы (₽, сроки) — только если тип работы объявляет меру результата; иначе — число проверенных работ и способ проверки. `empty` — честное пусто.

**Нельзя.** Токены, вызовы модели, число агентов, «сэкономлено часов»; числа, которых нет в ядре.

**`compact` (пульт в одно окно).** Фраза 28px; карточки «Изменилось» — сеткой, заголовок до двух строк, способ проверки переносится, без многоточий. Ссылка на доказательство — `evidenceHref`. Снятые работы («повод отпал») в «Итоге» не показываются — только числом «Снято» в «Потоке работы».

**Языки.** Каркас фразы — из словаря по локали: “Verified 9 work items of 12 submitted · 2 await your decision · nothing broken” / «Довела до проверенного результата 9 работ из 12 сданных · 2 ждут вашего решения · ничего не сломано». Формы числа — `Intl.PluralRules` (1 работу · 2 работы · 5 работ; 1 ждёт · 2 ждут). `unit` без значения — форма числа из словаря; переданный `unit`, `lead`, `empty` и заголовки изменений — данные, не переводятся.
