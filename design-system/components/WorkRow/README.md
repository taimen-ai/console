# WorkRow

Строка работы: статус, заголовок, номер вторым слоем, фраза готовности, четыре печати, давность, действие на месте.

**Когда.** Раздел «Работа» (группы по нужде), результаты поиска. Строка, которая ждёт смотрящего, — `mine`: подложка `accent-bg`, действие `human`. В плотности `compact` строка становится однострочной.

**Потребитель передаёт.** Фразу готовности («Сдано, 2 из 3 критериев прошли; ждёт вашего подтверждения») — из ядра.

**Ссылка и действие.** `href` — заголовок ведёт на страницу работы; `onAction` — действие на месте. **Узкий список** (контейнер `workrows`, ≤ 960px): название и фраза сверху, печати ниже, действие и давность справа — в колонках постоянной ширины (`--row-action-w` 176px, `--row-age-w` 80px), кнопки одной ширины стоят ровно друг под другом.
