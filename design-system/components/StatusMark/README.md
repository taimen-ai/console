# StatusMark

Знак операционного состояния: форма + слово, цвет — третьим каналом.

**Когда.** Строка работы, карточка исполнителя, критерии проверки. Десять состояний: `queued` пустой круг · `running` круг с центром (цвет машины) · `waiting_human` пунктирный круг (серый) · `waiting_external` пунктирный квадрат со стрелкой · `blocked` квадрат с чертой (`warning`) · `paused` две черты · `stale` часы, серое старение · `failed` треугольник (`error`) · `completed` контурная галочка, нейтральная · `verified` залитая галочка (`success`).

**Потребитель передаёт.** `label` — `displayName` статуса из типа работы; `machine` — категорию для tooltip. `mine` — только когда ждёт именно смотрящего: тогда `accent`.

**Нельзя.** Зелёный для `completed` («зелёный ≠ сделано: сделано — значит принято»); зелёный для старых данных; знак без слова.
