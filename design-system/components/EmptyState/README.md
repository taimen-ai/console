# EmptyState

Пустое состояние с одним действием; `art` — схема пути работы только для онбординга.

**Когда.** Пустой тенант — «Организация ещё не запущена» + «Установить пакет». Пустая зона — спокойный текст с последним событием («Ничего не ждёт вашей подписи · последняя — Иван, 12:40, из Telegram»), без действия.

**Нельзя.** Иллюстрации в рабочих экранах; больше одного действия.
