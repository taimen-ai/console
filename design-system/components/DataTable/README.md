# DataTable

Таблица справочника: заголовки колонок, строки с названием и сутью, табличные числа.

**Когда.** «База знаний» (договоры, документы, организации). Первая колонка — `tc-cell-title` (ссылка на запись) и `tc-cell-sub`; срок, который скоро истекает, — `tc-cell-warn`; источник — `SourceChip`.
